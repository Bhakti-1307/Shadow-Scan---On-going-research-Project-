# ShadowScan
### Explainable, AI-Assisted Cybersecurity Monitoring and Decision Support

**ShadowScan** is a long-term research and development initiative focused on developing an explainable, AI-assisted and local-first cybersecurity monitoring and decision-support framework.

The project aims to address the challenges faced by organisations with limited cybersecurity resources by helping responsible personnel understand, assess and respond to potential security threats.

## Vision

To develop a unified cybersecurity framework that can collect and analyse security information, identify suspicious activities, explain potential threats and assist human decision-making.

## Core Pipeline

**Detect → Explain → Correlate → Prioritise → Assist with Response**

The framework is intended to integrate multiple cybersecurity domains:

- Network Security
- User Security
- System Security
- IoT Security

## Guiding Principle

**Decision Support, Not Decision Replacement.**

ShadowScan aims to make cybersecurity information more understandable and actionable while keeping human personnel involved in security decisions.

## Research and Development Phases

| Phase | Research Direction |
|---|---|
| Phase 1 | Explainable Network Intrusion Detection |
| Phase 2 | Suspicious Activity and Anomaly Detection |
| Phase 3 | Security Event Correlation |
| Phase 4 | Risk Intelligence and Prioritisation |
| Phase 5 | IoT and Edge-Assisted Monitoring |

Each phase builds towards the broader ShadowScan framework through connected research, experimentation and prototype development.

## Current Status

**Phase 1: Explainable Network Intrusion Detection** has been completed as a proof of concept.

The first phase explores machine-learning-based network traffic classification and Explainable AI (XAI) using SHAP, supported by a Streamlit-based dashboard prototype.

Further phases are planned as part of the ongoing research and development process.

## Project Philosophy

ShadowScan is being developed as a continuous research initiative, with an emphasis on:

- Explainable and interpretable AI.
- Local-first and resource-conscious design.
- Human-centred cybersecurity.
- Modular and scalable development.
- Research-backed experimentation.

---

*ShadowScan is an ongoing research and development project. Its long-term vision represents proposed capabilities, not a claim that all components have already been implemented.*
